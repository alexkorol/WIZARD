# Vision

WIZARD is the **Verdigris Systems Laboratory**.

It stays a static, GitHub Pages-compatible dashboard. Modules are benches, not a monolithic client: each one should make an important Verdigris value inspectable, tunable, comparable, and exportable.

## What good looks like

- Reproducible scenario identity.
- Honest capability declarations.
- Canonical game data stays canonical.
- Owner proposals and player notes stay separate from authored content.
- Fixtures and events are small envelopes, not the production network protocol.

## What WIZARD is not

- A game engine.
- A shipping MMORPG client.
- A place to silently promote design notes into live tree/item/lattice data.

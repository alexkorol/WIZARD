# gui_framekit

WIZARD's reusable web GUI frame kit: tokens, frames, controls, HUD elements,
inventory widgets, and overlays — static, dependency-free, adoptable by every
submodule, and designed to port to C++ for Verdigris later.

**Read `INTERFACES.md` first — it is frozen and binding.** Work is dispatched
via `orchestration/boards/FRAMEKIT-WAVE-1.md`; coordinate per
`orchestration/BUS.md`.

Owner-facing demo: `index.html` (built by FK-108) once the wave lands.

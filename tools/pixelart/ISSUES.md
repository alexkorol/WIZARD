# Pixel Art Creator Issues and Improvements Tracking

## Current Issues

### Drawing Tools
- [ ] Only basic pixel drawing available
- [ ] No eraser tool (have to use white color)
- [ ] No undo/redo functionality
- [ ] No line or shape tools
- [ ] No fill tool

### Canvas Management
- [ ] Limited canvas size options (only 16x16, 32x32, 64x64)
- [ ] No canvas resizing without clearing
- [ ] No layer support
- [ ] No transparent background support
- [ ] No canvas border customization

### User Interface
- [ ] Basic color picker with no palette management
- [ ] No tool size options
- [ ] No preview window
- [ ] No zoom functionality
- [ ] Limited grid customization

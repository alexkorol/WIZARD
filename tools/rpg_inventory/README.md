# Advanced ARPG Inventory System

A flexible and interactive inventory management system inspired by classic Action RPGs. Features a grid-based layout with equipment slots, item management, and persistent storage.

## Features

- **Grid System**: Flexible grid-based inventory layout
- **Equipment Slots**: Character silhouette with specific slots
- **Item Management**: Drag and drop functionality
- **Rarity System**: Color-coded item rarities
- **Item Mechanics**: Stacking and rotation capabilities
- **Information Display**: Detailed item tooltips
- **Data Persistence**: Local storage save system
- **Responsive Design**: Adapts to different screen sizes

## Current State

The tool is stable and functional with core features implemented:
- Basic inventory grid system
- Equipment slot functionality
- Item drag and drop
- Rarity color coding
- Local storage integration
- Tooltip system
- Basic item stacking

## Usage

The Inventory System can be accessed through:
1. The main WIZARD dashboard
2. Directly via `tools/rpg_inventory/index.html`

### Quick Start Guide
1. Drag items between inventory slots
2. Use equipment slots for character gear
3. Stack similar items automatically
4. Hover over items for details
5. Items save automatically to local storage

## Technical Details

Built using:
- HTML5 Drag and Drop API
- JavaScript for inventory logic
- Local Storage for data persistence
- CSS Grid for layout
- Custom event system

## Integration

To integrate this component into another project:
1. Copy the necessary HTML, CSS, and JavaScript files
2. Include the required dependencies
3. Initialize the inventory system
4. Customize styling and configuration as needed

## Dependencies

- Modern web browser with Drag and Drop support
- JavaScript enabled
- Local Storage enabled
- CSS Grid support

# Advanced ARPG Inventory System

A flexible and interactive inventory system inspired by classic Action RPGs. This app is part of the WIZARD project.

## Features
- Grid-based inventory system
- Equipment slots with character silhouette
- Item rarity system with color coding
- Drag and drop functionality
- Item stacking system
- Item rotation capability
- Tooltip system with item details
- Responsive design
- Custom scrollbar styling

## Getting Started
```bash
git clone https://github.com/yourusername/wizard.git
cd wizard/tools/rpg_inventory
```
Open `index.html` in your browser to use the inventory system.

## Usage
- Drag and drop items between slots
- Click rotation button to rotate items
- Hover over items to see details
- Stack similar items automatically
- Equipment slots accept only appropriate item types
- Items are saved to local storage automatically

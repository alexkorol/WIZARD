# Visual Faction Moodboards v3 — audit only

These boards are retired and must not be attached to generation requests.
Their source selection treated Alex's pasted type examples too much like a
ready-made library and did not enforce historical-cluster faction locks before
layout. The active replacements are in `../faction-moodboards-v4/`.

Each board is a `2048x3072` (2:3 portrait) organic collage with:

- two approved faction ladder/loadout anchors;
- six user-supplied or curated Pinterest-like visual-direction references;
- irregular overlap, scale, rotation, and edge cropping;
- no generated/staged item studies; and
- no added labels beyond the faction name.

## Historical workflow only

1. Attach prompt-specific ladder reference A.
2. Attach prompt-specific ladder reference B.
3. Attach one matching board from this folder as Image C.
4. Paste the corresponding wildcard paperdoll prompt.

Images A/B are the only authority for faction, tier, materials, construction,
item membership, and coherent loadout design. Image C supplies visual energy,
silhouette breadth, equipment-family variety, and ARPG readability. Do not
copy or hybridize its pictured objects.

# Visual Faction Moodboards v4

These are the active Image C references for manual web wildcard generation.
Each `2048x3072` board uses an organic portrait collage, two approved faction
ladder anchors, and six newly researched visual-direction sources.

Faction locks are enforced by the builder and recorded in `manifest.json`:

- North: Nordic Bronze Age + Mycenaean/Aegean Bronze Age.
- Stonewood: Mesoamerican + Tlingit/Haida cedar-and-hide construction.
- Dustwind: Scythian/Saka steppe only.
- Riverspill: Predynastic/ancient Egyptian + Sumerian/Akkadian only.

Alex's pasted examples were used to define the desired reference type and
visual energy, not copied as the source library. Ordinary staged item studies
remain excluded.

## Web-app use

1. Attach prompt-specific ladder reference A.
2. Attach prompt-specific ladder reference B.
3. Attach the matching v4 board as Image C.
4. Paste the corresponding wildcard paperdoll prompt.

Images A/B remain the only authority for faction, tier, materials,
construction, item membership, and coherent loadout design. Image C supplies
visual energy and breadth only. Never copy or hybridize its pictured objects.

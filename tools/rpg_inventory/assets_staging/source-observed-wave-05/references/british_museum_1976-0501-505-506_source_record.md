# British Museum source record: 1976,0501.505–506

Accessed 2026-07-24 for the Wave 05 `preparation_bronze_grinder`
replacement-source audit.

## Official object records

- Pestle component, 1976,0501.505:
  <https://www.britishmuseum.org/collection/object/H_1976-0501-505>
- Mortar component, 1976,0501.506:
  <https://www.britishmuseum.org/collection/object/H_1976-0501-506>

These are two sequential registration numbers, not one accession number. The
British Museum describes them as one set. Both records give the same findspot,
King Harry Lane Cemetery burial 203, and the same excavation/small-find code,
SB/DH. Both cite Jackson 2010 catalogue number 436. Jackson's British Museum
concordance lists the complete set as `1976,0501.505-6`.

## Catalog metadata

- Object type: cosmetic-grinder.
- Culture/period: Romano-British.
- Context: King Harry Lane Cemetery, burial 203, St Albans.
- Excavator named on the pestle record: Dr Ian M Stead.
- Material field: copper alloy.
- Pestle description begins: bronze cosmetic-grinder, pestle component,
  suspension loop at one end.
- Mortar description begins: copper alloy cosmetic grinder, mortar component,
  plain, with suspension loop at one end.
- Acquisition: donated by William Old Ltd; mortar record gives acquisition
  date 1976.
- Location: on display in Room 49, Roman Britain, Display Case 4.
- Neither object record publishes dimensions or a production-date field.

Independent archaeological context summaries citing Stead and Rigby identify
King Harry Lane grave 203 as cemetery Phase 3, approximately AD 40–60. Use
this only as contextual dating, not as a date printed in the British Museum
record.

## Catalog construction and mechanics

The two object records repeat the same complete-set description:

- end-looped mortar and end-looped pestle;
- both cleaned to a dull golden-brown metallic surface;
- both finely finished castings;
- possible intentional axial asymmetry;
- low, broad elliptical mortar bow;
- plain convex mortar walls and partially flattened keel;
- capacious broad V-section groove with an off-centre basal wear slot;
- bulbous knobbed mortar terminal with neat neck moulding;
- slender ring-like mortar loop, out of alignment with the bow when viewed
  above the groove;
- slender circular-section pestle rod;
- pestle is plumpest toward its upturned tip, whose slight sideways turn may
  be intentional;
- wear facet on the pestle's convex face;
- circular ring-like pestle loop with simple neck moulding mirroring the
  mortar loop;
- the pestle fits snugly in the mortar groove.

No animal or human figure, inscription, hinge, case, lid, gemstone, celestial
motif, or extra kit component is described. "Plain" does not mean featureless:
the knobbed terminal, ring loops, simple neck mouldings, off-centre wear slot,
and slight axial asymmetry remain construction evidence.

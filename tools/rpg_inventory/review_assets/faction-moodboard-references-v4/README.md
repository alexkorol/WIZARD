# Active v4 moodboard references

This folder contains only the 24 curated visual-direction images selected by
`core/build_faction_visual_moodboards_v4.py`: six per faction. Each faction
subfolder is a hard source boundary, not a loose visual category.

Do not add an image here until its culture/period cluster and faction lock have
been reviewed. Alex's pasted examples normally define the reference type to
research; they are not automatically copied into this library.

# SLerp: Smooth Color Interpolation Tool

A pixel art palette generator and color interpolation tool designed for creating smooth color transitions and shading palettes. This tool is part of the WIZARD project.

## Features
- Generate color palettes for pixel art
- Create smooth transitions between colors
- Save and load custom palettes
- Export palettes in various formats
- Real-time preview of color transitions
- Support for different color spaces (RGB, HSL)

## Getting Started
```bash
git clone https://github.com/yourusername/wizard.git
cd wizard/tools/slerp
```
Open `index.html` in your browser to use the tool.

## Usage
- Select base colors using the color pickers
- Choose number of interpolation steps
- Toggle between RGB and HSL interpolation
- Click colors to copy their hex codes
- Export palette in various formats
- Preview shading results on pixel art samples

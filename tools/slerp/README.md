# SLerp: Smooth Color Interpolation Tool

A sophisticated color palette generator and interpolation tool designed specifically for pixel art. Creates smooth color transitions and shading palettes with support for multiple color spaces and export options.

## Features

- **Color Interpolation**: Generate smooth transitions between colors
- **Multiple Color Spaces**: Support for RGB and HSL interpolation
- **Real-time Preview**: Instant visualization of color transitions
- **Export Options**: Save palettes in various formats
- **Palette Management**: Save and load custom palettes
- **Sample Preview**: Test palettes on pixel art samples

## Current State

The tool is stable and functional with core features implemented:
- Basic color interpolation
- RGB and HSL color space support
- Palette export functionality
- Real-time preview system
- Sample visualization

## Usage

The SLerp tool can be accessed through:
1. The main WIZARD dashboard
2. Directly via `tools/slerp/index.html`

### Quick Start Guide
1. Select your base colors using the color pickers
2. Choose the number of interpolation steps
3. Select your preferred color space (RGB/HSL)
4. Preview the results in real-time
5. Export your palette in desired format

## Technical Details

Built using:
- JavaScript for color calculations
- HTML5 Canvas for previews
- Custom color space conversion algorithms
- Local storage for palette saving
